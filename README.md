## 🔑 如何取得免費的 Google Gemini API Key？ (How to get your free Google Gemini API Key?)

想要使用本工具，您需要一把開啟 Google AI 的鑰匙。這把鑰匙目前是**完全免費**的！
To use this tool, you’ll need a key to unlock Google AI—and right now, it’s totally **free**!

**Step 1. 登入與前往 (Sign in)**
請先登入您的 Google 帳號，然後點擊此連結前往 **[Google AI Studio](https://aistudio.google.com/)**。
Log into your Google account, then click this link 👆to go to Google AI Studio.

**Step 2. 找到按鈕 (Find the button)**
進入頁面後，點擊左上角藍色的 **「Get API key」** 按鈕。
Once you’re on the page, hit the blue **“Get API key”** button in the top-left.

**Step 3. 建立鑰匙 (Create the key)**
在跳出的畫面中，點擊 **「Create API key」**。
In the pop-up, click **“Create API key.”**

**Step 4. 複製保存 (Copy and save)**
畫面會產生一串長長的代碼（以 `AIza` 開頭），請點擊旁邊的 **「Copy」** 按鈕複製下來。
You’ll get a long code that starts with `AIza`. Click the **“Copy”** button next to it to grab it.

**Step 5. 啟動 Wizard (Fire up the Wizard)**
回到 App 網頁，將鑰匙貼入左側的 **「Google Gemini API Key」** 欄位，按下 Enter，即可開始施法！✨
Go back to the app page, paste the key into the **“Google Gemini API Key”** field on the left, press Enter, and you’re ready to work your magic! ✨
